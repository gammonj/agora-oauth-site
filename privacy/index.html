Privacy Policy

Agora Comms Interpreter is a private, non-commercial application operated for the personal use of its owner. It helps organise school-related communications into structured actions, events and reference information.

Google data accessed

The application uses Google OAuth with read-only permissions for Gmail and Google Drive. It may read selected school-related email messages and selected files from a designated Google Drive folder.

The application does not send, delete, archive, relabel or otherwise modify Gmail messages. It does not create, edit, move or delete Google Drive files.

How Google data is used

Selected communication text and selected document content may be sent to the OpenAI API solely for semantic interpretation, such as identifying relevant actions, dates, events, requirements and durable school information.

The resulting structured data is stored in the owner's private, self-hosted Agora Comms system. Google account credentials, OAuth tokens and API keys are not sent to OpenAI as part of the interpretation content.

Sharing and sale of data

Google user data is not sold, used for advertising, or shared with unrelated third parties. Access is limited to services necessary to operate the personal workflow described above, including Google APIs, the OpenAI API, and the owner's private self-hosted Agora Comms system.

Data retention

Structured information derived from school communications may be retained in the owner's private Agora Comms system for as long as it remains useful for personal school administration. Source communications remain subject to the retention settings of the owner's Google account.

Security

OAuth tokens and application secrets are stored outside the public source repository. The main Agora Comms application is private and is not exposed as a public web service.

Revoking access

The owner can revoke the application's Google account access at any time through Google Account security settings. Revoking access prevents future Gmail and Google Drive reads by the application.
